# Laratter（タイムリミット追加版）

受講番号：6th-28

## 1. プロダクトの紹介

講義で作成した SNS アプリケーション「Laratter」に，**時間経過によるツイート自動削除機能**を追加しました．

- 投稿したツイートに対し1分以内にいいねがつかなければ自動削除される
- いいねされたツイートは永続的に残り続ける。いいねが一つもつかず1分が経過したツイートは、画面再読み込みをすると自動的に削除される
- 自分のコメントにはいいねをつけることができない。他アカウントからのみいいねが可能。
- 時間経過でツイートが赤くなるように変更。具体的には、残り時間が30秒を切ると徐々にツイートが赤くなり、ユーザーを焦らせる。

時間経過による削除機能を追加した理由は、元になっているTwitterなどのSNSアプリでまだ見たことがない機能だったから、授業で習っていないリアルタイム機能を用いた機能(ジョブの活用)を付けるにはどうすればいいか学びたかったから。


## 2. こだわった点・苦労した点

- ジョブを触るのが初めてだったので、使い方に苦労した。最初は1分毎に全てのツイートを確認しいいねがついていない時間が1分を超えたものを削除するという実装にしようとしていたが、正確な時間が測れない、ずっとジョブを回し続けなければならず負荷が大きいという問題に直面し、ツイートの作成時間を取得→取得した時間+1分し、計算した時刻を過ぎたツイートを削除する方式に変更した。
- 一方「削除まであと〇〇」という表示はカウントダウンだったため、最初は1分から一秒ずつ引いてみせる実装方式にしようとしていたが、タブを非表示にしてからもう一度見ると時間のずれが起きていることに気付き、期限時間まであと何秒かを計算する方式に変更した。
- なるべくユーザーを焦らせたかったため、段階的にツイートが赤色になる機能を実装した。また、ズルができないように自分からはいいねを付けることができないようにした。
## 3. 操作方法

1. sail立ち上げ後、「./vendor/bin/sail artisan queue:work」でジョブを起動する。
2. トップページから「ログイン」または「新規登録」を行う。
3. 「Tweet 作成」からツイートを作成する
4. 「Tweet 一覧」に該当ツイートと削除までのタイムリミットが表示されている。
5. 別アカウントでログインし、該当ツイートにいいねをつける。
6. いいねをつけられたコメントはタイムリミット表示が消えている。一方、いいねがつけられなかったツイートは30秒を切ると徐々に赤くなり、0秒になって画面を再読み込みすると自動で削除されている。
